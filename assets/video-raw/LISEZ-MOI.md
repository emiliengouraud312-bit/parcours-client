# Déposez les vidéos ici

Glissez les fichiers MP4 dans ce dossier, **sans les renommer**.

Le script de traitement lit le numéro de chapitre directement dans le nom du
fichier (les deux premiers chiffres). Les noms produits par Veo conviennent
tels quels :

| Fichier | Chapitre |
|---|---|
| `01_Cutting_strapping_on_clothing_bale_…mp4` | 01 · Réception |
| `02_Hands_loading_laundry_into_washer_…mp4` | 02 · Lavage |
| `03_Steaming_wrinkles_from_polo_shirt_…mp4` | 03 · Repassage |
| `04_Hands_adjusting_polo_shirt_1080p_…mp4` | 04 · Prise de vue |
| `05_Hands_scrolling_smartphone_on_table_…mp4` | 05 · Mise en ligne |
| `06_Hands_packing_polo_shirt_into_…mp4` | 06 · Emballage et expédition |

Déposez les fichiers **bruts**, pleine qualité : ne compressez pas, ne
recadrez pas. La coupe, l'encodage (WebM VP9 + MP4 H.264, 720×1280) et les
posters sont faits par `npm run media`.
